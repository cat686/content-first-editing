# 评测方案（尚未执行跨模型实验）

`cases.jsonl` 为原创虚构测试用例，不是事实材料。逐条输入给同一模型，分别比较无 Skill、原始八条规范、当前 Skill，必要时加入其他 Skill 基线。保持模型、参数、输入及输出要求一致；盲评、随机交换答案顺序，至少两名评审独立判断。

硬门槛：无新增无据事实、无实质信息遗漏、无证据强度或立场变化、无越权修改。任何失败单列，不被文风高分抵消。

通过硬门槛的结果再按 1–5 分评价：读者理解成本、信息有效性、逻辑衔接、文体适配、编辑必要性。对于原样保留用例，非必要改动计为失败；不以删字比例、AI 检测分数作为目标。可记录长度变化和脚本差异作为辅助观测。长文和专业术语由领域评审另行确认。

未来可加入多模型、每种文体多篇真实授权稿件及人工信息单元标注，报告置信区间、分歧与失败样例。当前用例仅覆盖部分常见风险，不宣称通过。
