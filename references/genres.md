# 文体适配

先遵循用户或目标机构的实际规范。以下为编辑时的默认关注点，而非写作模板。

| 文体 | 优先保留、突出 | 避免 |
| --- | --- | --- |
| 实验报告 | 仪器、材料、条件、步骤、原始数据、误差及可复现性；区分测量与解释 | 为了连贯删实验步骤或异常值；把实验结果写成普遍规律 |
| 科研论文 | 研究缺口、方法、证据、术语、引用、效应量、局限、学术语体 | 扩大创新性、删必要限定、机械改写引用或将结果和讨论混淆 |
| 理论征文、评论 | 核心论点、概念、前提、反例、价值立场、推论与事实的区分 | 把作者立场淡化为泛泛而谈；用口号替代论证 |
| 调研报告 | 样本、时间地点、调查方式、数据口径、现状、原因证据及建议对象 | 以个案概括整体；未经证据断言根因；删除调查方法 |
| 技术文档 | 操作主体、条件、版本、参数、接口、输入输出、异常与边界 | 过度散文化；取消有用的步骤、列表和代码；随意更改 API 名称 |
| 科普、解释性文章 | 核心概念、读者所需的定义、类比的边界、真实例子 | 追求字数最少而省去必要解释；使用不准确的类比 |
| 新闻与事实型文章 | 时间、主体、来源、事实与引述的区分、必要背景 | 擅加评价、情绪、动机、未核实的细节 |
| 随笔、观点文章 | 作者真实语气、个性用词、立场、节奏与经历 | 将个人风格统一成公文腔；编造个人故事 |

## 论文各部分

- 摘要：保留研究对象、方法、主要结果、结论和关键范围；不为去重删摘要中的核心结果。
- 引言：保留背景到研究问题的逻辑；删只剩时代口号的铺垫。缺口应有材料支持。
- 方法：可复现性优先于短句、主动语态或压缩；必要的被动表达允许保留。
- 结果：明确观察对象、条件与比较基准；不把未检验的机制加入结果。
- 讨论：区分解释、假设、外推和不确定性；保留有依据的限制与替代解释。
- 结论：回应研究问题，不机械复述全部结果；必要核心数据可再次出现。
- 图表和注释：不得改变单位、编号、统计说明、显著性标记和引用。仅在授权内优化措辞。

## 读者层次

专家文本保留专业术语与精确限定；跨学科文本可在首次出现时解释原稿已给出的术语定义；入门文本保留有教学功能的重复、例子与步骤。缺少定义时另行建议，不编造定义或新增材料。英文稿按英文习惯编辑，不强制移植中文风格规则。
